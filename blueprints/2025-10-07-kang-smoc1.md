## 3. 论文思路逐步拆解

### 3.1 原始计数

论文使用 10x Genomics Single Cell 3’ v3.1、NovaSeq 6000；主要数据用 Cell Ranger 6.1.1 和 GRCh38-2020-A，snRNA-seq 纳入 intronic reads。新项目应保存 Cell Ranger 版本、参考基因组、化学版本和每个 donor 的样本表。

输入契约：

- 每个样本一个 10x matrix；
- sample_sheet.tsv 至少含 sample_id、donor_id、condition、modality、batch；
- gene_annotation.tsv 含 Ensembl ID、gene symbol、gene biotype；
- velocity 另需与 GRCh38 注释一致的 loom。

### 3.2 质控、环境 RNA、双细胞和整合

论文报告的阈值：

- nCount_RNA >= 500；
- nFeature_RNA >= 250；
- log10(nFeature_RNA) / log10(nCount_RNA) > 0.80；
- mitochondrial fraction < 0.20；
- SoupX 污染估计 20%；
- DoubletFinder 去除双细胞；
- Seurat SCTransform 整合 scRNA 与 snRNA。

alpha 细胞先按 GCG、CRYBA2、PCSK2、TTR 高表达筛选，再按 Louvain/Seurat 邻居图分群；少于 10 个细胞的簇并入最近邻。

必须保存的质量表：

1. donor 级过滤前后细胞数、基因数、线粒体比例、doublet 比例；
2. SoupX 前后 GCG/INS 的变化；
3. AB（GCG+ INS+）群体的 doublet、stress、donor 分布和 multiome 支持；
4. integration 前后 donor_id 和 modality。

### 3.3 alpha 亚群和功能模块

论文使用五个 alpha 状态：alpha1、alpha2、alpha3、alpha4、AB，并把三个 beta 状态纳入参考。alpha2 带有增殖/细胞周期特征，AB 是多激素和祖细胞/β-cell pathway 特征。作者用 escape 逐细胞计算 MSigDB C2/C5 富集、ANOVA 比较亚群，并用 AddModuleScore 计算 beta marker、beta transcription factor 和 stress 模块。

推荐输出：

- cell_metadata.tsv：donor、modality、condition、cluster、cell_state、doublet、stress、module scores；
- marker_table.tsv：marker、log fold-change、检测率和统计单位；
- pathway_scores.tsv；
- alpha_state_summary.csv：按 donor 汇总状态组成。

### 3.4 scRNA/snRNA 联合 RNA velocity

论文用 velocyto 按 GRCh38 生成 loom；读取 Seurat UMAP 和 alpha/beta 标签转成 AnnData；用 scVelo proportions 计算 spliced/unspliced 比例，以 stochastic model 估计 velocity，PAGA 画连接，velocity confidence 做局部方向质量评估。作者的理由是 snRNA 保留更多 intron-retention 的早期动态，而 scRNA 更接近成熟胞质 mRNA。

非糖尿病参考中的四条主轨迹：

1. AB -> beta2 -> beta1；
2. beta3 -> alpha4 -> alpha2；
3. AB -> alpha4 -> alpha2；
4. alpha3 -> alpha2。

速度输入契约：

- sample.loom：spliced 和 unspliced；
- seurat_umap.tsv：cell_id、UMAP_1、UMAP_2；
- cell_labels.tsv：cell_id、cell_state、donor_id、condition；
- barcode 必须一一映射并记录丢弃数。

只有 snRNA 时要把 intronic 计数和不确定性写进结果，不能当作普通 scRNA 的速度结果。

### 3.5 Monocle3 和多轨迹共同基因

论文把 Seurat 坐标、标签和表达转成 Monocle3 对象，按 PAGA 起点设置 root，用 graph_test 计算基因与伪时间的关联，再按表达模式聚类。对三条走向 alpha 的轨迹 B/C/D 取交集，得到：

SMOC1、PLCE1、PAPPA2、ZNF331、ALDH1A1、SLC30A8、BTG2、TM4SF4、NR4A1、PCSK2。

之后按基因是否有非零标准化表达分成 positive/negative，计算 GO Biological Process 的 pancreatic alpha-cell differentiation score 并画 ridge plot。

可迁移改进：

- 同时保存 PAGA root、Monocle3 root 和替代 root；
- 共同基因在 donor bootstrap 或 pseudobulk 级别重复；
- 同时报告检测率、表达量和 donor 一致性，不能只用非零；
- 共同基因只是候选程序，必须进入外部队列和独立实验验证。

### 3.6 HPAP/HIRN 外部投影

论文处理 13 位 ND 和 13 位 T2D 供体，以更新后的 alpha/beta 参考投影细胞类型和 UMAP。Monocle3 root 由 PAGA 指定：ND 以 AB 为根，T2D 以 beta1 为根。ND 更复杂、偏双向；T2D 更偏 beta1 -> beta3 -> AB -> alpha 或 beta1 -> alpha1 -> alpha2。

必须保留年龄、BMI、HbA1c、样本处理和 donor 等混杂因素。不能把每个细胞当成独立生物学重复做最终疾病检验。

### 3.7 multiome 与功能验证边界

multiome 用 Seurat 5.2.0、Signac 1.14.0 和 weighted nearest neighbor，支持 AB 双阳性及调控可及性。SMOC1 还通过人胰岛/EndoC-betaH1 过表达、重组蛋白、qPCR、GSIS、Ca2+ flux、cAMP、免疫染色和电镜验证。后者不属于纯生信流程，却决定候选标志物能否上升为功能候选基因。

## 4. R-first 开箱执行顺序

~~~text
sample_sheet + 10x matrices
  -> per-sample QC / SoupX / DoubletFinder
  -> donor-aware SCTransform integration
  -> canonical annotation
  -> alpha/beta state map
  -> escape / module scores
  -> velocyto loom -> scVelo -> PAGA
  -> Monocle3 -> graph_test -> commonality
  -> HPAP projection + multiome check
~~~

~~~bash
python scripts/validate_blueprints.py
Rscript R/00_install_and_check.R
Rscript R/01_qc_integrate.R --input data/tenx --sample-sheet data/sample_sheet.tsv --config config/smoc1.yml --out results/qc_integrated
Rscript R/02_reference_projection.R --rds results/qc_integrated/integrated.rds --config config/smoc1.yml --out results/reference
python python/02_velocity_paga.py --loom data/velocity/integrated.loom --metadata results/reference/velocity_metadata.tsv --out results/velocity
Rscript R/03_monocle_commonality.R --rds results/reference/reference.rds --velocity results/velocity/velocity_metadata.tsv --out results/commonality
~~~

没有真实数据时不要伪造结果；脚本会把输入检查、barcode 映射和中间表写到输出目录。

## 5. 证据等级和失败处理

| 观察 | 可以支持什么 | 不能单独支持什么 |
| --- | --- | --- |
| marker/module score | 细胞状态或功能相似性 | 细胞谱系转换 |
| scVelo/PAGA | 局部转录动力学的模型推断 | 真实时间顺序和因果 |
| Monocle3 gene association | 与伪时间一致的表达程序 | 驱动基因 |
| 多轨迹共同基因 | 候选优先级 | 直接机制 |
| ND/T2D 外部投影 | 疾病状态关联可复现 | 人体内真实转换 |
| multiome 可及性 | 调控层面的独立支持 | 功能必然改变 |
| 扰动实验 | 功能/因果方向 | 对所有 donor 普遍成立 |

失败处理：loom barcode 不匹配就停止速度分析；confidence 偏低时比较 scRNA-only、snRNA-only 和联合结果；root 改变导致方向反转时不下单一方向结论；AB 只在一个 donor 出现时标为 donor-specific；HPAP 投影不稳定时按 donor 做混淆矩阵；没有 intronic 计数时删除 velocity 证据。
